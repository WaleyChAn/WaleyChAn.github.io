# Project instructions

- This is the source for WaleyChAn's playable cat-planet homepage.
- Use Three.js/TypeScript for the browser and Blender for editable character assets.
- Keep `docs/` unchanged: it is the retained archive of the previous website.
- Do not commit credentials, local auth directories, `node_modules`, or Blender backups.
- Runtime characters must export as GLB with +Y up, +Z forward and Idle/Walk clips.
- Inspect actual front, side, back, and walking renders when changing character geometry.
- Run `npm test` and `npm run build` before publishing.
- Source branch: `master`. Static GitHub Pages output: root of `gh-pages`.
- Publish only when requested. Never force-push source history.
- Distinguish CPU model renders and Node tests from actual WebGL/browser acceptance.
